# Report chapters

Markdown chapters for the project report. They describe only what is in the
repository; every number is taken from [../RESULTS.md](../RESULTS.md), which is
generated from the metrics files by `perception-service/evaluation/`.

| # | Chapter |
|---|---|
| 1 | [Abstract](01_abstract.md) |
| 2 | [Introduction and problem statement](02_introduction.md) |
| 3 | [Literature survey](03_literature_survey.md) |
| 4 | [System architecture](04_architecture.md) (Mermaid diagrams) |
| 5 | [Module description](05_modules.md) |
| 6 | [Implementation details](06_implementation.md) |
| 7 | [Testing and results](07_testing_and_results.md) |
| 8 | [Limitations and future scope](08_limitations_future.md) |
| 9 | [Conclusion](09_conclusion.md) |
| 10 | [Ethics, privacy and responsible use](10_ethics_privacy.md) |

Items marked **[verify]** are facts the code does not establish (for example
the exact source of a dataset). Check them before submitting.

Mermaid diagrams render on GitHub and in VS Code (Markdown Preview Mermaid
Support). To put one in a Word report, paste it into https://mermaid.live and
export it as PNG or SVG.
